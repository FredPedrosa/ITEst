# Individual Trajectory Estimation Shiny Apps (HLM & 4PL)

This repository contains the code for two Shiny web applications (one in Portuguese - `EstTI.R`, one in English - `ITEst.R`) designed to estimate and visualize individual trajectories from sequential score data. The apps implement two distinct modeling approaches:

1.  A custom **Harmonic Linear Model (HLM)** that combines cyclical patterns with linear trends.
2.  A standard **4-Parameter Logistic (4PL)** model, suitable for sigmoid (S-shaped) growth or decline patterns.

These tools can be applied in various fields, such as monitoring progress in therapeutic processes, learning curves, or any domain where tracking individual change over time is relevant.

## Features

*   **Dual Modeling:** Implements both the HLM and 4PL models for flexible trajectory analysis.
*   **HLM Implementation:**
    *   Uses `optim` to fit a model incorporating harmonic (sine/cosine) components and an internal linear trend.
    *   Includes a simple linear fit (`lm`) for comparison.
    *   Combines predictions using a custom R²-weighted average.
    *   Provides R² for components and the combined model.
    *   Includes residual normality testing (Shapiro-Wilk) and diagnostic plots (Q-Q, Residuals vs. Fitted).
*   **4PL Implementation:**
    *   Utilizes `nls_multstart::nls_multstart` for robust fitting of the 4-parameter logistic model, reducing sensitivity to starting values.
    *   Identifies the best-fitting model based on residual sum of squares from multiple start attempts.
    *   Provides parameter estimates (lower/upper asymptotes, inflection point, hill slope) and R².
*   **User Interface:**
    *   Allows users to input comma-separated scores.
    *   Provides options to set Y-axis limits for plots.
    *   Enables selection of which model(s) (HLM, 4PL, or both) to run.
*   **Output & Interpretation:**
    *   Displays trajectory plots (`ggplot2`) for each selected model.
    *   Generates automated textual interpretations summarizing the key findings and parameters for both HLM and 4PL models.
    *   Presents results in separate tabs for clarity.
*   **Bilingual:** Offers two separate apps with interfaces and interpretations in Portuguese (`EstTI.R`) and English (`ITEst.R`).

## How it Works

1.  **Input:** The user provides a sequence of scores and selects the desired model(s).
2.  **HLM Process (if selected):**
    *   The `EstIT_HLM` function optimizes harmonic + linear trend parameters via `optim`.
    *   A simple `lm` is fitted.
    *   Predictions are combined using an R²-weighted average.
    *   R², residuals, and diagnostic tests are calculated.
    *   A plot and interpretation are generated by `interpret_HLM`.
3.  **4PL Process (if selected):**
    *   The `EstIT_4pl` function uses `nls_multstart` to perform multiple non-linear least squares fits of the 4PL model, varying starting parameters.
    *   The function iterates, attempting to find a set number of converged models. Console messages indicate progress. *Note: This step can take some time.*
    *   The converged model with the lowest residual sum of squares is selected as the best fit.
    *   R², parameter estimates, and a plot are generated.
    *   An interpretation is generated by `interpret_4pl`.
4.  **Output:** The Shiny app displays the plots and textual interpretations for the selected models in corresponding tabs.

## Usage

### Running Locally

1.  **Prerequisites:** Ensure you have R and RStudio (recommended) installed.
2.  **Install Packages:** Open R/RStudio and install the required packages if you haven't already:
    ```R
    install.packages(c("shiny", "ggplot2", "nls.multstart"))
    ```
3.  **Clone Repository:** Clone this repository to your local machine.
    ```bash
    git clone <repository-url> 
    cd <repository-directory>
    ```
4.  **Run App:**
    *   Navigate to the directory containing the app file within RStudio or your R console.
    *   Use the `runApp()` function:
        ```R
        # To run the Portuguese app
        shiny::runApp("EstTI.R") 

        # To run the English app
        shiny::runApp("ITEst.R")
        ```
### Using the Deployed Apps

Access the live applications via the links provided in the [Applications Overview](#applications-overview) section. Remember that the 4PL model fitting may take a few moments to complete after clicking "Run Analysis".

## Input Requirements

Users need to provide the following information in the sidebar panel:

1.  **Scores:** A comma-separated string of numeric scores in chronological order (e.g., `35, 36, 35, 31, 32, 35, 41, 47, 43`).
2.  **Minimum/Maximum Score Limit:** Numeric values to set the Y-axis limits on the output plots.
3.  **Model Choice:** Checkboxes to select whether to run the HLM, the 4PL model, or both.

## Output Interpretation

The main panel displays results in tabs:

*   **HLM Tab (if selected):** Shows the plot of raw scores overlaid with the HLM fitted line, followed by a textual interpretation generated by `interpret_HLM`, summarizing R², normality, parameters, and trend.
*   **4PL Tab (if selected):** Shows the plot of raw scores overlaid with the best-fitting 4PL curve, followed by a textual interpretation generated by `interpret_4pl`, summarizing R², asymptotes, inflection point, slope (hill), and trajectory direction.
